# 미구현·개선 백로그

작성 기준: 2026-07-30. 실기기 확인과 코드 감사를 함께 반영한다.
표시 규칙 — P0 사용자가 바로 막히는 것, P1 핵심 경험, P2 다듬기, P3 이후 과제.

## 방금 고친 것
- 운동 종료 후 "피드에 공유"가 실제로 게시되지 않던 문제. 게시물 저장에 미디어를 선택 항목으로
  바꾸고 세션 볼륨·시간·세션 id를 함께 남기도록 했다.

## P0 — 사용자가 바로 막히는 것
| 항목 | 현재 | 해야 할 일 |
|---|---|---|
| 설정 화면 프로필 | `SettingsViewData.mock`(이름 "존", 레벨 12) 하드코딩 | 실제 프로필(닉네임·레벨)로 교체하거나 해당 카드 제거 |
| 캐릭터 탭 프로필 페이지 | `profile_page.dart`가 "목업 전용" 안내를 그대로 노출 | 라우팅에서 제외했는지 확인하고 미사용이면 삭제 |
| 파티 목록 화면(구버전) | `party_list_page.dart`가 목업 스낵바 사용 | 신규 파티 탭으로 대체되었는지 확인 후 삭제 |

## P1 — 핵심 경험
| 항목 | 현재 | 해야 할 일 |
|---|---|---|
| 피드 카드 저장·공유 | 저장 버튼 일부가 빈 동작 | 저장 토글과 공유(클립보드) 동작 확인 및 연결 |
| 알림 생성 | 테이블·화면은 있으나 좋아요·댓글·팔로우 시 알림을 넣지 않음 | 각 동작 성공 후 대상에게 알림 insert |
| 파티 채팅 | 패널이 아직 목업 | `partyMessagesProvider`·`sendMessage` 연결 |
| 종목 가이드 | 상세 화면은 있으나 루틴 상세에서 진입 불가 | 루틴 상세 종목 타일 탭 → 종목 상세 |
| 프로필 팔로워 수 | 0 고정 | follows 집계로 채우기 |
| 동기화 검증 | 코드만 있고 실기기 확인 안 됨 | 로그인 → 기록 → 재설치 → 복원 확인 |

## P2 — 다듬기
| 항목 | 내용 |
|---|---|
| 영상 재생 | 피드·게시물의 영상이 정지 이미지로만 표시된다. 재생 화면 필요 |
| 사진 캐러셀 | 여러 장 업로드·스와이프 미지원(현재 1장) |
| 게시물 삭제·수정 | 본인 게시물 관리 기능 없음 |
| 신고·차단 | 공개 피드 운영에 필요(스토어 심사에서도 요구될 수 있음) |
| 루틴 프리셋 | `assets/routine_presets.json` 준비됨, 앱에서 사용 안 함 |
| 파티 프리셋 | `assets/party_presets.json` 준비됨, 생성 시트에서 하드코딩 목록 사용 |
| FAQ·도움말 | `assets/help_faq.json` 준비됨, 화면 없음 |
| 통계 심화 | 1RM 추이, 종목별 진척 |
| 빈 상태 일관성 | 화면별 문구·아이콘 통일 |
