# Legacy UI Mock Port Design

## Decision

GitHub 이력의 React 화면을 Flutter 모바일 앱으로 이식한다. 이식본은 사용자가 화면과 흐름을 확인하는 프레젠테이션 전용 목업이며, 기존 API와 데이터베이스는 연결하지 않는다.

`docs/PROJECT_CONTEXT.md`의 개발 순서는 유지하되, P4~P6에는 실제 기능이 아닌 UI 목업만 허용한다. 이 예외는 레거시 화면 검토를 위한 것이며, 파티·피드·캐릭터의 도메인과 원격 연동을 앞당기지 않는다.

## Legacy source

기준 소스는 Flutter 전환 직전 커밋 `1f7bed9`의 `frontend/src/`다.

- 공통 시각 언어: `#0d0d0d` 앱 배경, `#242424` 카드, `#ff3d3d` 강조색, 흰색 본문과 회색 보조 텍스트.
- 화면: 로그인, 회원가입, 운동 시작·진행·완료, 내 파티·파티 방·활동 피드, 캐릭터 미리보기와 설정.
- 레거시의 서버 호출은 모두 제거하고, 동일한 버튼과 입력 흐름은 로컬 상태와 안내 메시지로 재현한다.

## Navigation and presentation

앱은 로그인 화면으로 시작한다. 빈 값이 아닌 목업 로그인을 수행하면 하단 탭 앱 셸로 진입한다.

- 홈: 오늘의 운동 요약과 바로 시작 버튼.
- 기록: 운동 시작, 진행 중 세트 입력, 완료 요약을 한 화면 상태 전환으로 표시한다.
- 통계: P2 이전임을 명확히 하는 시각적 준비 화면을 표시한다.
- 파티: 파티 목록, 생성·초대 코드 입력, 랜덤 파티 카드, 파티 방의 멤버·활동 피드·반응을 표시한다.
- 프로필: 캐릭터 레벨·신체 부위 잠재력과 운동 취향 태그·프로필 저장 목업을 표시한다.
- 로그인과 회원가입은 탭 바 밖의 라우트이며, 파티 방은 파티 탭에서 여는 세부 라우트다.

Material 기본 아이콘을 사용해 레거시의 이모지 의존성을 없애고, 모든 탭·버튼은 44dp 이상의 터치 영역과 의미 레이블을 가진다. 외부 이미지와 네트워크 폰트는 사용하지 않는다.

## State and boundaries

공유 데이터 계층을 만들지 않는다. 각 화면의 `StatefulWidget`이 필요한 목업 상태만 소유한다.

- 인증: 입력이 비어 있지 않으면 홈으로 이동한다.
- 운동: 시작 → 진행 → 완료 상태, 예시 세트 목록, 경과 시간과 완료 안내를 메모리에서만 처리한다.
- 파티: 예시 파티와 활동을 표시하고, 생성·가입·반응 버튼은 즉시 화면 상태 또는 스낵바로 피드백한다.
- 프로필: 운동 취향 태그 선택과 저장 안내를 로컬 상태로 처리한다.

Repository, domain entity, DTO, Drift, Supabase, HTTP, 파일 접근 권한, 클립보드 영속화는 추가하지 않는다.

## File boundaries

- `lib/core/theme/`: 색상 토큰과 Flutter `ThemeData`.
- `lib/core/router/`: `go_router` 라우트와 앱 셸 진입점.
- `lib/features/*/presentation/`: 각 UI 목업 화면. feature 간 import 없이 라우터와 Flutter 표준 위젯만 사용한다.
- `lib/main.dart`: ProviderScope와 로컬라이제이션·라우터를 연결하는 앱 루트.
- `lib/l10n/app_ko.arb`: 이번 목업에 추가되는 모든 사용자 노출 한국어 문자열.

## Validation

- 앱 시작 시 로그인 화면이 보이고, 로그인 후 홈·기록·통계·파티·프로필 탭으로 이동한다.
- 운동 화면은 시작·세트 추가·종료가 서버 없이 이어진다.
- 파티 화면은 파티 방을 열고, 반응을 누르면 수치가 바뀐다.
- `flutter analyze`, `flutter test`, `flutter build apk --debug`가 모두 성공한다.

## Non-goals

- 실제 운동 DB, 세트 영속화, 1RM·볼륨 계산, 휴식 타이머, 통계 차트.
- 실제 로그인, 초대 코드 검증, 멤버십, 피드 동기화, EXP, 영상 촬영·업로드.
