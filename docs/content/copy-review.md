# 헬셋로그 앱 내 문구 감수 및 개선 제안 문서

본 문서는 `lib/l10n/app_ko.arb` 및 앱 화면 코드에 작성된 한국어 텍스트의 어색한 표현, 어미 불일치, 용어 혼용, 개발용 내부 용어 노출 문제점들을 분석하고 개선안을 제안하는 문서입니다.

---

## 1. 개요 및 감수 원칙

1. **존댓말 표현 통일**: 안내 및 상태 문구는 격식 있는 정중한 어미('~습니다', '~하세요')로 일관되게 적용합니다.
2. **버튼 명칭 일관성**: 사용자 동작을 유도하는 주요 버튼은 명사형('저장', '시작', '가입', '종료')으로 통일합니다.
3. **오류 문구 명확화**: 단절된 에러 표현 대신 **[원인] + [해결 안내]** 형태를 포함하여 유저의 후속 행동을 가이드합니다.
4. **용어 통일**: 동일한 개념에 대해 혼용되고 있는 용어를 앱 정체성에 맞게 하나로 고정합니다.
   - `운동` vs `워크아웃` -> **운동**으로 통일
   - `가입` vs `참가` -> **가입**으로 통일
   - `헬셋로그` vs `HELL-LOG PRO` -> **헬셋로그**로 통일
   - `세트로그` vs `운동 기록` -> **운동 기록(세트로그)**으로 가이드 정리
5. **개발 내부 용어 제거**: 유저에게 노출되는 시스템 문구에서 개발 단계 표현('P2', 'P5', 'P6', '목업')을 전면 제거합니다.

---

## 2. 문구 감수 및 개선 표

| `registerIntro` | 파티에 참여할 준비가 되셨나요? | 용어 불일치('참여' 대신 '가입') | 헬셋로그 파티에 함께할 준비가 되셨나요? |
| `startWorkout` | 운동 시작하기 | 버튼 어미 불일치 ('~하기' 어미 사용) | 운동 시작 |
| `join` / `joinParty` | 가입하기 / 가입 | 동일 동작 버튼 어미 불일치 ('가입하기' vs '가입') | 가입 |
| `potentialAccumulated` | 잠재력이 누적됐어요 | 해요체 어미 사용 및 직관적이지 않은 문구 | 운동 기록이 정상적으로 축적되었습니다 |

| `statsDescription` | 기록이 쌓이면 볼륨과 1RM 변화를 보여드릴게요. | 해요체 어미 사용 | 운동 기록이 누적되면 주간 볼륨과 변화를 보여드립니다. |
| `statsLater` | 통계는 P2에서 연결됩니다 | 개발 단계 용어('P2') 유저 노출 | 상세 통계 기능 준비 중 |

| `statsNoData` | 아직 기록된 운동이 없어요 | 해요체 어미 사용 | 아직 기록된 운동이 없습니다 |
| `statsNoDataDescription` | 운동을 기록하면 이번 주의 변화를 볼 수 있어요. | 해요체 어미 사용 | 운동을 기록하면 주간 변화를 확인할 수 있습니다. |
| `statsLoadError` | 통계를 불러오지 못했어요 | 구체적 원인 및 해결 방법 부재, 해요체 어미 사용 | 통계 데이터를 불러오지 못했습니다. 네트워크 연결 상태를 확인 후 다시 시도해 주세요. |
