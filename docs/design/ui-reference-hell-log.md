# UI/UX 참조 분석 — HELL-LOG 목업 (색감 제외)

> 사용자 제공 프로토타입에서 IA·UX·기능만 추출. 색/브랜딩은 우리 것 유지. SSOT 단계에 매핑하고 스코프 플래그.

## 참조 앱 구조
- **하단 네비 5**: 홈(피드) / 운동 / (센터 액션) / 파티 / 설정
- **홈** = 소셜 피드: 스토리(라이브) + 운동 포스트(유저·LV·운동태그 `BENCH 80KG×4`·+XP·좋아요/댓글/공유)
- **운동** = 서브탭 3: **세트로그 / 몬스터 / 통계**
  - 세트로그: Today's Lift, **XP 예상획득 바("몬스터 성장 중 ▲")**, 운동블록(세트행 SET/KG/REPS/✓), +세트추가, 휴식타이머, +운동추가, "운동완료·피드 공유"
  - 몬스터: 캐릭터(이름/LV/타입) + **부위별 스탯 그리드(ARM/LEG/CORE/ENDURE)** + EXP바
  - 통계: This Week(운동일/XP/볼륨) + Weekly Volume 바차트 + **부위별 분할(CHEST/LEGS/BACK/SHOULDER %)**
- **파티** = 서브탭 3: 내파티 / 탐색 / 채팅
  - 내파티: 파티카드(멤버·미션진행률) + RANDOM MATCH + 친구초대
  - 탐색: 검색 + 부위별 카테고리 필터 + PRO전용파티 + 목록
  - 채팅: 파티 채팅
- 모달: 랜덤매치 / 초대 / PRO업셀 / 알림 / **영상공유(카메라 녹화)**
- 설정: 프로필, 알림토글, 프라이버시(피드 공개범위), 앱설정(단위 kg/lb), **PRO 구독(₩4,900/월)**

## 우리 계획에 매핑

### 지금 반영 (P1~P2, 색 제외)
1. **IA 재구성**: `운동` 탭 하나에 **세트로그/통계(+나중 몬스터)** 서브탭으로 통합. 현재 우리 네비(홈/기록/통계/파티/프로필)보다 깔끔. → 라우터/셸 조정.
2. **통계 부위별 분할**(P2-02): 근육군별 볼륨 %. 우리 `WorkoutSet→muscleGroup`로 바로 계산 가능. P2-02 스펙에 포함.
3. **세트 완료 = 운동완료 시 피드 공유 CTA** 자리만(공유는 P4/P5, 버튼 UX만 참고).
4. **운동 요약 태그**(`BENCH 80KG×4` 칩) — 세션 요약 표시에 활용.

### 단계 매핑 (해당 단계서)
- 몬스터 **부위별 스탯(ARM/LEG/CORE/ENDURE)** + 부위별 성장 → **P6 캐릭터**(이미 확정한 부위별 성장 모델과 일치, 스탯명 구체화).
- XP 예상획득 바 → P6(캐릭터 EXP 배선). P1~P5는 자리만.
- 파티 채팅 / 미션 / 탐색·카테고리 → **P4 파티** 확장.
- 영상 공유(카메라) → **P5**.
- 랜덤 매치 → P4 이후(운동성향 필터 전제, 데이팅 변질 주의).

### ⚠️ SSOT 신규 스코프 (제품정의 확장 — 사용자 결정 필요)
현재 SSOT에 **없는** 것들. 넣으려면 `PROJECT_CONTEXT.md` 갱신 후 진행:
- **글로벌 홈 피드 + 스토리** (SSOT는 파티 내 피드만 있음. 전체 소셜 피드는 신규)
- **PRO 유료 구독**(수익모델) — SSOT에 수익화 없음
- **파티 채팅**(실시간 메시징) — P4 정의는 "생성/초대/멤버피드"만
- **랜덤 매칭 / 탐색·카테고리** — 낯선사람 매칭(데이팅 변질 리스크, 조사도 경고)
- **친구 시스템**(팔로우/초대)
