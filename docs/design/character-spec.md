# HealSetLog 캐릭터 디자인 스펙 (v0 · 도트/픽셀아트)

> 방향 확정용 v0. 실제 아트는 나중에 반복 수정 전제. 벡터 실루엣 컨셉 시트는 `character-evolution.html` 참고.

## 방향
- **캐릭터 = 픽셀아트(도트)**, UI 크롬(아이콘/HUD) = 벡터. 하이브리드.
- 톤: 포켓몬(3세대급 스프라이트) ~ 디지몬(로키→얼티밋) 진화 감성. 레트로 게임 도파민.
- **선형 진화 5단계** (분기 진화는 P6 이후 별도).

## 스프라이트 규격
- 베이스 캔버스 **96×96 px**, 앱에서 nearest-neighbor 확대(픽셀 또렷 유지).
- 팔레트 스프라이트당 **8~16색** (픽셀아트 제약 = 정체성).
- 애니메이션 최소셋(단계당):
  - `idle` 2프레임 (숨쉬기)
  - `cheer` 3프레임 (세트 완료 시 — 역기 들기/주먹)
  - `evolve` 버스트 1컷 (레벨업 진화 연출, 공용 이펙트 재사용 가능)
- 파일: 단계별 스프라이트시트 PNG. (아트 생성은 픽셀아트 이미지 모델/아티스트 몫 — 나는 raster 직접 생성 불가.)

## 스탯 컬러 = 팔레트 스왑
Lv.25부터 지배적 스탯의 액센트 램프를 트림/오라 레이어에 팔레트 스왑. 베이스 실루엣은 동일, 색만 교체(런타임 쉬움).
- **근력 strength** → crimson 램프 `#7a1f22 / #ff4d54 / #ffb3b6`
- **지구력 endurance** → cyan 램프 `#0e4a63 / #38bdf8 / #bfe9ff`
- **꾸준함 consistency** → gold 램프 `#7a5a12 / #f5c542 / #ffe9a8`

## 부위별 성장 + 합산 진화 (v1 — 핵심 모델)
> **이건 SSOT §5 확장.** 구현 전 SSOT §4/§5를 먼저 갱신해야 함(문서 먼저 규칙). 구현은 **P6**.

- **부위별 성장**: 근육군(chest/back/shoulders/legs/arms/core)마다 개별 레벨. 소스 = 기존 `WorkoutSet.exerciseId → Exercise.muscleGroup` 볼륨 누적(P1-02 데이터로 계산 가능, 새 트래킹 불필요).
  - 부위 EXP = 해당 근육군 완료세트 볼륨 기반(정확한 계수는 P6에서 SSOT §5에 확정).
  - 프로필 화면: 근육군별 **게이지/레이더 차트**로 부위별 성장 표시(진화 사이 구간의 피드백).
- **진화 트리거 = 합산**: 부위별 레벨 총합이 문턱(1/10/25/50/100) 넘으면 다음 스테이지 폼으로 진화. (전역 단일 EXP가 아니라 부위합.)
- **하이브리드 시각화**: 스테이지 5폼 × **바디타입 변주**. 지배적 근육군군에 따라:
  - `상체형` (chest/back/shoulders/arms 우세) — 어깨·팔 벌크
  - `하체형` (legs 우세) — 다리 벌크
  - `균형형` (고른 분포) — 기본
  - → 5폼 × 3변주 ≈ **15 스프라이트**. 기존 agy 생성 5개 = 균형형 베이스.
- 팔레트 스왑(근력/지구력/꾸준함)은 이 위에 얹는 색 레이어(직교).

## 연동 (SSOT §4/§5)
- `Character` 엔티티: `stage`(1~5) = 부위합 레벨 경계에서 전환. `bodyType`(상체/하체/균형) = 지배 근육군.
- EXP·레벨 규칙은 SSOT §5 기반. **부위별 EXP 모델은 §5에 추가 필요(P6).**
- 세트 완료 시 `cheer` 애니 + 햅틱(P1-03 이미 햅틱까지). EXP 연출/레벨업 `evolve`는 **P6**에서 배선.

## 안 하는 것 (v1)
- 분기 진화(스탯형 별도 종점), 스킬트리, 아이템/재화, 커스터마이즈 — 전부 P6 이후.
- 부위별 스프라이트 파츠 모핑(개별 부위 크기 실시간 변형) — 하이브리드 변주로 대체(조합 폭발 회피).
- 실제 스프라이트 15종 제작 — 방향 확정 후 별도(균형형 5종은 v0 존재).
