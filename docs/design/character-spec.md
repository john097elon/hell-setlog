# HealSetLog 캐릭터 디자인 스펙 (v0 · 도트/픽셀아트)

> 방향 확정용 v0. 실제 아트는 나중에 반복 수정 전제. 벡터 실루엣 컨셉 시트는 `character-evolution.html` 참고.

## 방향
- **캐릭터 = 픽셀아트(도트)**, UI 크롬(아이콘/HUD) = 벡터. 하이브리드.
- 톤: 포켓몬(3세대급 스프라이트) ~ 디지몬(로키→얼티밋) 진화 감성. 레트로 게임 도파민.
- **선형 진화 5단계** (분기 진화는 P6 이후 별도).

## 스프라이트 규격
- 베이스 캔버스 **96×96 px**, 앱에서 nearest-neighbor 확대(픽셀 또렷 유지).
- 팔레트 스프라이트당 **8~16색** (픽셀아트 제약 = 정체성).
- 애니메이션 최소셋(단계당):
  - `idle` 2프레임 (숨쉬기)
  - `cheer` 3프레임 (세트 완료 시 — 역기 들기/주먹)
  - `evolve` 버스트 1컷 (레벨업 진화 연출, 공용 이펙트 재사용 가능)
- 파일: 단계별 스프라이트시트 PNG. (아트 생성은 픽셀아트 이미지 모델/아티스트 몫 — 나는 raster 직접 생성 불가.)

## 스탯 컬러 = 팔레트 스왑
Lv.25부터 지배적 스탯의 액센트 램프를 트림/오라 레이어에 팔레트 스왑. 베이스 실루엣은 동일, 색만 교체(런타임 쉬움).
- **근력 strength** → crimson 램프 `#7a1f22 / #ff4d54 / #ffb3b6`
- **지구력 endurance** → cyan 램프 `#0e4a63 / #38bdf8 / #bfe9ff`
- **꾸준함 consistency** → gold 램프 `#7a5a12 / #f5c542 / #ffe9a8`

## 연동 (SSOT §4/§5)
- `Character` 엔티티: `stage`(1~5)는 위 레벨 경계(1/10/25/50/100)에서 전환.
- `CharacterStat`(strength/endurance/consistency) 최고값 → 팔레트 스왑 대상 결정.
- EXP·레벨 규칙은 SSOT §5 그대로 (`game_rules.dart`). 스펙은 형태·색만 정의, 게임 수치 재정의 안 함.
- 세트 완료 시 `cheer` 애니 + 햅틱(P1-03 이미 햅틱까지). EXP 연출/레벨업 `evolve`는 **P6**에서 배선.

## 안 하는 것 (v0)
- 분기 진화, 스킬트리, 아이템/재화, 커스터마이즈 — 전부 P6 이후.
- 실제 스프라이트 제작 — 방향 확정 후 별도.
